How it works

Three steps from unknown to patched.

No guessing at version numbers and no cross-referencing spreadsheets. PatchIt does the matching and Morphe Manager does the patching.

1

Scan

PatchIt reads the packages installed on your device: version name and code, split APKs, signing certificate, install dates and APK size.

2

Match

Each app is checked per source — by versionCode first, version name second — and given an honest verdict, from supported to too new.

3

Patch

Send the covering repositories to Morphe Manager through its real add-source deep link and patch from there.

Verdicts

An honest answer for every app.

Each app gets one of six verdicts, computed per source. No source means no patch, and PatchIt says so rather than pretending.

Supported

A source covers this exact build.

Experimental

Supported, but the source marks this version experimental.

Untested

The source covers the app but declares no versions, so nothing is verified.

Too new

Your build is newer than any the sources support. Patches may fail.

Too old

Your build is older than any the sources support.

No patches

No source in the registry has patches for this app.

Install

Install in under a minute.

PatchIt ships as a signed APK. You'll need Android 6.0 or newer and "install unknown apps" enabled for the installer.

  1. Download the APK. Grab the latest release from GitHub Releases.
  2. Allow the install. Android will ask you to grant PatchIt permission to install unknown apps — this is required for in-app updates too.
  3. Grant access. PatchIt needs QUERY_ALL_PACKAGES to enumerate your installed apps. Nothing is uploaded anywhere.
  4. Scan and patch. Open the app, review the verdicts, and send the sources you trust to Morphe Manager.

Build from source

# requirements: Node 20+, JDK 21, Android SDK 35

Good to know

Permissions, licence and trust.

Permissions

  • QUERY_ALL_PACKAGES — enumerate installed apps.
  • INTERNET — fetch patch indexes and updates.
  • REQUEST_INSTALL_PACKAGES — hand updates to Android's installer.

Not affiliated

PatchIt is not affiliated with the Morphe project. Only add patch sources you trust — a source decides what ends up inside your patched apps.
